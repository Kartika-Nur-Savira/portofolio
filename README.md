# Portfolio — Kartika Nur Savira

Personal portfolio website built with Next.js, TypeScript, and Tailwind CSS.

## Run Locally

Clone repository:

```bash
git clone https://github.com/Kartika-Nur-Savira/portofolio.git
```

Masuk ke folder project:

```bash
cd portofolio
```

Install dependencies:

```bash
npm install
```

Jalankan development server:

```bash
npm run dev
```

Buka di browser:

```text
http://localhost:3000
```
